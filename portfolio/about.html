About me

Get to know me

I’m a Data Science student from Pakistan with a strong interest in programming, data and problem solving. Most of my work sits at the intersection of Python and the web: writing scrapers that collect real data, analysing that data, and building interfaces that present it clearly.

I work regularly with Python for data analysis, web scraping and the fundamentals of machine learning, and with Java for object-oriented programming and data structures. On the web side I build responsive sites using HTML, CSS and JavaScript, and I use Git and GitHub to version everything I build.

I prefer learning by building. Each project on this site came from wanting to solve a specific problem — collecting product data, understanding a dataset, or organising study time — and each one taught me something I now reuse.
